Command Center: Privacy Policy

Effective September 21, 2026. Updated October 15, 2026.

Command Center is a personal dashboard built and used by a single person. It is not offered to the public, and only its owner can sign in. This policy describes what data the app touches and what happens to it.

Data the app accesses

  • Google Calendar (read-only): event titles, times and locations, to show the owner's schedule.
  • Gmail (read-only): for unread inbox messages from the last 14 days, the sender, subject line, snippet, timestamp and Important label, to show an unread list. Message bodies and attachments are not requested.
  • Canvas (school LMS): assignment names, due dates and submission status, to show coursework.
  • Spotify: the currently playing track and playback controls, through the owner's own Spotify login.

Other services the app sends requests to

  • Google Routes API: the owner's home and campus addresses, to get live drive times.
  • Open-Meteo: the campus and home coordinates, to get the weather.
  • Cloudflare Workers AI: when the owner uses Talk, the question plus a short summary of coursework, calendar, unread subjects and notes, so the answer comes from the owner's own data. (Only if an Anthropic API key is configured does this go to Anthropic instead.)
  • Substack: public RSS feeds of publications, for the daily quote. Nothing about the owner is sent.

The app requests only the read-only scopes calendar.readonly and gmail.readonly. It cannot send, change, delete or label anything in your Google account.

What is stored

The app stores the following in Cloudflare Workers KV, in the owner's own Cloudflare account: the Google OAuth refresh token and a short-lived access token, the latest Canvas snapshot, the owner's notes, and the items the owner has dismissed. Calendar and Gmail content is fetched on demand to display it and is not saved.

Sharing

Data is not sold, shared with third parties, used for advertising, or used to train any model. Apart from the requests listed above, it is sent only to the owner's own browser. The app is hosted on Cloudflare, which processes requests on the owner's behalf.

Google API Services User Data Policy

Command Center's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

You can revoke Command Center's access at any time at myaccount.google.com/permissions. The owner can delete all stored data by deleting the app's Cloudflare KV namespace.
